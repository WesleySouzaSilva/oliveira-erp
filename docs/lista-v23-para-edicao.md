# Lista para a migração V23 — edite este arquivo

**Como usar:** apague as linhas que NÃO quiser importar. Mantenha o que está bom.
Quando terminar de olhar, me avise ("pode gerar a V23") e eu monto a migração
exatamente com o que sobrar deste arquivo — um item = uma linha de cadastro.

Convenção (importante para eu ler certo):
- item = linha que começa com `- ` (ex.: `- Intimações Judiciais`)
- só os blocos abaixo valem como lista; este texto de instrução é ignorado
- nada de listar duas vezes o mesmo nome — o banco recusa duplicidade por organização

Origens (verificado, detalhe em `plano-seed-tipos-tarefa-bancos.md`):
- tipos = lista de "Tipo de tarefa" do ADVBOX (captura da tela; 240 lá, 5 repetidos
  já tirados, sobram 235)
- bancos = combo fixo do fonte antigo (17; "Outro" não entra, é texto livre)
